# §8.1 — Compute the coverage matrix and its Pareto frontier

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Every multi-cohort analysis silently chooses a variables-versus-cohorts trade-off. Making the frontier an artifact turns that choice into a defensible decision rather than a side effect of whichever subset happened to join cleanly.

## I/O

```
IN   canonical rows + the pack's variable list
OUT  coverage/matrix.parquet   (cohort_id, variable, n_persons, frac_present)
     coverage/frontier.json    [{n_variables, n_cohorts, n_persons, variables}]
     coverage/frontier.png
SIDE none
```

## Contract

```
# A point on the frontier: no other subset gives MORE cohorts at
# this variable count, or more variables at this cohort count.
{ "n_variables": 8, "n_cohorts": 5, "n_persons": 2140,
  "variables": ["age","sex","ecog","stage","line","pdl1_tps","os","pfs"],
  "dropped_cohorts": ["COHORT_D"] }

# frac_present counts NON-MISSING among linked persons, so a cohort
# with the column and no values reads 0.0 — not absent (see §2.3).
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| coverage_min_frac | 0.8 | 0.0..1.0 | the fraction at which a cohort counts as carrying a variable | config |
| frontier_max_subsets | 100000 | 10^3..10^7 | enumeration cap; above it the search is greedy and says so | config |
| required_variables | [] | variable list | variables every frontier point must include (usually the outcome) | pack |

## Alternatives

Seam: FrontierSearch — frontier(matrix) -> [Point]

| alternative | why you'd swap | swap cost |
|---|---|---|
| greedy forward selection | linear; scales past 30 variables | can miss the true frontier, so the output must be labelled approximate |
| ILP over the subset lattice | exact at larger scale than enumeration | a solver dependency for a plot most readers skim |

## Trap

Counting a variable as covered when the column exists. Presence of a column and presence of values are different facts, and conflating them produces a frontier that promises data the imputation stage then has to invent.

## Not here (nogo)

Do not select an operating point — emit the frontier and stop. Never drop a cohort from the matrix because it covers little; that is the finding.
