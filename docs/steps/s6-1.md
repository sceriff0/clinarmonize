# §6.1 — Apply concept mappings into OMOP rows

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

A source code is a string in someone's database; a standard concept is the only thing the CDM lets you query on. Making that translation explicit and rule-addressed is what turns a pile of cohorts into something a network study can read.

## I/O

```
IN   linked cohort tables + rules/ruleset.json + pinned vocabulary
OUT  mapped/<domain>.parquet   one row per (person, concept, datetime)
     mapped/_unmapped.parquet   every source value with no standard concept
SIDE none
```

## Contract

```
# Both ids are kept. source_concept_id is what makes the map reversible.
{ "person_id": int, "cohort_id": str,
  "<domain>_concept_id": int,          # STANDARD concept
  "<domain>_source_value": str,        # verbatim source string
  "<domain>_source_concept_id": int,   # non-standard, pre-translation
  "<domain>_datetime": timestamp,
  "rule_id": str, "rule_version": str }
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| cdm_version | 5.4 | 5.3|5.4 | the target table shapes | config |
| cdm_domains | [person, condition_occurrence, drug_exposure, measurement, observation] | enum list | the five-table subset; the pipeline never claims full conformance | config |
| max_unmapped_frac | 0.2 | 0.0..1.0 | above this fraction of values unmapped, the run fails | config |
| keep_source_concept | true | boolean | retains the pre-translation concept; turning it off breaks --audit | config |

## Alternatives

Seam: ConceptMapper — map(value, Rule, Vocabulary) -> [OmopRow]

| alternative | why you'd swap | swap cost |
|---|---|---|
| OHDSI ETL-Synthea style SQL | battle-tested; runs inside the warehouse | rule provenance becomes per-query rather than per-cell |
| emit source concepts only | lossless; defers every mapping decision | output is no longer queryable as OMOP, which is the whole point |

## Trap

Dropping source_concept_id once the standard concept is found. The source-to-standard map is many-to-one, so without it the distinction the source cohort recorded deliberately is unrecoverable and --audit cannot walk back.

## Not here (nogo)

Do not invent a concept id for an unmapped value — write it to _unmapped.parquet. Never consult an unpinned vocabulary. Do not derive any endpoint; that is §7.

```
           where measurement_source_concept_id is null"
```
