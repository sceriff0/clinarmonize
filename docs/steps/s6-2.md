# §6.2 — Convert units through UCUM, refusing ambiguity

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

A unit error is the failure most likely to survive every downstream check: the values look plausible, the type is right, and only a distribution comparison against another cohort exposes it. Refusing an ambiguous conversion is cheaper than detecting one.

## I/O

```
IN   mapped/<domain>.parquet + rules (unit_in, unit_out) + pack ranges
OUT  same rows, value_as_number converted; unit_concept_id set
     qc/unit_conversions.json  [{rule_id, from, to, factor, n_rows}]
SIDE fails the run on an ambiguous or missing conversion factor
```

## Contract

```
convert(v, "mg/dL", "mmol/L", analyte) -> v * factor(analyte)
# There is NO universal mg/dL -> mmol/L factor: it is molar-mass
# specific. A conversion without an analyte is an error, not a default.

post-condition: pack.plausible_range contains p1..p99 of the result
                else -> qc flag `implausible_after_conversion`, run fails
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| unit_conversion_table | assets/ucum_factors.yaml | path | analyte-aware factors; the only source of conversions | config |
| fail_on_implausible_range | true | boolean | a converted distribution outside the pack range stops the run | config |
| plausible_range_quantiles | [0.01, 0.99] | two floats | which quantiles the range check uses, so outliers alone cannot fail it | config |

## Alternatives

Seam: UnitConverter — convert(value, from, to, analyte) -> value

| alternative | why you'd swap | swap cost |
|---|---|---|
| a UCUM library | full grammar; arbitrary compound units | still cannot supply analyte-specific molar factors, which is the hard half |
| store both raw and converted | nothing is ever lost | doubles the measurement table and moves the ambiguity downstream |

## Trap

Assuming a single factor per unit pair. mg/dL to mmol/L differs for glucose and creatinine, so an analyte-blind table produces values that are plausible, wrong, and indistinguishable from real biological variation.

## Not here (nogo)

Do not guess a unit when candidate_units was empty. Never convert to a unit the pack does not declare. Do not silence the range check with a wider range.
