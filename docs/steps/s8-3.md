# §8.3 — Emit the per-cohort standardized-difference forest

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Cohorts differ, and a difference large enough to be learned as a cohort effect will leak batch into any downstream model. Reporting standardized differences per variable makes transportability an inspectable property rather than an assumption.

## I/O

```
IN   canonical rows + coverage matrix
OUT  coverage/std_diff.parquet (variable, cohort_id, smd, ci_low, ci_high)
     coverage/std_diff_forest.png
SIDE none
```

## Contract

```
smd = (mean_cohort - mean_pooled) / pooled_sd          # continuous
    = (p_cohort - p_pooled) / sqrt(p_bar*(1-p_bar))    # binary

# |smd| > 0.1 is the conventional imbalance flag. Outcome-flagged
# variables ARE included here — this is reporting, not a mapping
# decision, so §0's invariant does not bind it. That distinction
# is the reason §10.1 tests the PROPOSER, not the whole pipeline.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| smd_flag_threshold | 0.1 | 0.0..2.0 | the imbalance line drawn on the forest plot | config |
| smd_bootstrap_n | 1000 | 0..10^5 | bootstrap replicates for the interval; 0 emits a point estimate only | config |
| smd_include_outcomes | true | boolean | reporting-only use of outcome variables; never feeds a mapping decision | config |

## Alternatives

Seam: BalanceMetric — compare(cohort, pooled, variable) -> Estimate

| alternative | why you'd swap | swap cost |
|---|---|---|
| a cohort-membership classifier's AUC | one number for overall separability | says cohorts differ but not in which variable, which is the actionable half |
| Kolmogorov–Smirnov per variable | distribution-shape sensitive, not just means | not comparable across variable types; no conventional threshold |

## Trap

Computing SMD against the pooled mean including the cohort itself. With few cohorts the cohort dominates its own reference, shrinking every difference towards zero — exactly when the report matters most.

## Not here (nogo)

Do not adjust, reweight or correct anything. Never let an SMD result feed back into a mapping decision — that would violate §0.
