# §10.3 — The generality test — a different disease, unmodified

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Generality claimed is generality lost. The only convincing evidence is a green run on a cohort set from a different clinical domain with a different pack, with not one line of the pipeline changed.

## I/O

```
IN   a non-oncology cohort set + assets/packs/critical-care.yaml
OUT  a complete result set: OMOP subset, manifest, provenance, coverage
     tests/generality/grep_report.txt
SIDE fails the build on any disease term found in modules/ or workflows/
```

## Contract

```
nextflow run . -profile test_full,docker \
  --concept_pack assets/packs/critical-care.yaml

# AND the grep, which is a build step, not a habit:
grep -riE 'melanoma|nsclc|carcinoma|RECIST|MS4A4A|HARTWIG|TCGA' \
     modules/ workflows/ | tee tests/generality/grep_report.txt
test ! -s tests/generality/grep_report.txt

# RECIST is in the list deliberately: it belongs to an oncology PACK,
# never to §7.3's logic, which reads `criteria_version` from config.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| concept_pack | assets/packs/minimal.yaml | path or url | swapping it is the entire generality test | CLI |
| generality_terms | assets/forbidden_terms.txt | path | the grep list; adding a term is cheap and should be routine | config |
| generality_paths | [modules/, workflows/] | path list | where logic lives; assets/ is deliberately excluded | config |

## Alternatives

Seam: GeneralityAudit — audit(paths, terms) -> [Violation]

| alternative | why you'd swap | swap cost |
|---|---|---|
| a linter with an allowlist | fewer false positives on comments and docstrings | an allowlist is where exceptions accumulate until the check means nothing |
| run three packs in CI | much stronger evidence of generality | CI time roughly triples for a property one pack already demonstrates |

## Trap

Grepping for words only. The subtler leaks are numeric — a plausible range hard-coded because "TPS is 0–100", a default unit chosen for one assay, a derivation assuming progression precedes death. None is caught by a word list.

## Not here (nogo)

Do not exempt a path from the grep to make it pass. Never let the non-oncology run be optional. Do not add a disease term to assets/ logic files.
