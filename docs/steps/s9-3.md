# §9.3 — Render the report from results only

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

A report that recomputes drifts from the pipeline and cannot be re-rendered without re-running it. Making results/ the render process's only input enforces principle 11 mechanically: raw data is not staged, so a recomputing report cannot run.

## I/O

```
IN   path results        # the ONLY input — no raw data is staged
OUT  results/_site/       browsable HTML
SIDE none
```

## Contract

```
process RENDER_REPORT {
    input:  path results
    output: path "_site"
    script: "quarto render report --output-dir _site"
}
# report/  index.qmd  qc.qmd  results.qmd  provenance.qmd
# A .qmd may READ results/**.parquet and *_manifest.json and render
# them. It may not load a raw input, fit a model, compute a
# statistic, or derive an endpoint.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| report | true | boolean | renders the Quarto site as a terminal process | config |
| report_title | Harmonization run | string | cosmetic; appears in the site header | config |
| report_include_counts | true | boolean | off when cohort-level counts are disclosure-sensitive | config |

## Alternatives

Seam: Reporter — render(resultsDir) -> SiteDir

| alternative | why you'd swap | swap cost |
|---|---|---|
| MultiQC only | no Quarto dependency; nf-core native | no narrative sections, and custom plots become JSON gymnastics |
| a static site built in CI | decouples rendering from the run entirely | the report can then be built from a results set that no run produced |

## Trap

Letting one .qmd compute "just the median" from a raw table. The report now has a number the pipeline never wrote, so it cannot be reproduced from results/ and the delete-the-inputs test fails.

## Not here (nogo)

Never stage a raw input into this process. Do not fit a model or compute a statistic in a .qmd. Do not publish a report whose numbers are absent from results/.

```

```

The render succeeds with every raw input deleted — principle 11's actual test.
