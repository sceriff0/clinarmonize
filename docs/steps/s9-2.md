# §9.2 — Write the mapping manifest and per-cell provenance

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

The manifest is what makes a rerun comparable and a result citable: pack version, vocabulary hash, container digests, params hash. Provenance is what makes a single surprising number answerable rather than argued about.

## I/O

```
IN   ruleset, pack, vocabulary hash, container digests, params
OUT  results/mapping_manifest.json
     results/provenance.parquet
     (target_table, target_row_id, target_field, cohort_id, dataset_id,
      source_column, source_value, rule_id, rule_version)
SIDE none
```

## Contract

```
{ "pipeline_version": "1.0.0",
  "analysis_git_sha": "…",
  "concept_pack":    {"name":"oncology-ici","version":"1.2.0","sha256":"…"},
  "vocabulary":      {"release":"athena-2026-08","sha256":"…"},
  "containers":      [{"process":"PROFILE","digest":"sha256:…"}],
  "params_hash": "…",
  "unsealed": [],                # mirrors unseal.log; empty is the norm
  "counts": {"cohorts":5,"persons":2140,"rules":214} }

# The generality check is a grep, and it is a build step:
grep -riE 'melanoma|nsclc|MS4A4A|HARTWIG' modules/ workflows/   # must be empty
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| emit_provenance | true | boolean | per-cell provenance; off makes --audit impossible | config |
| provenance_sample_frac | 1.0 | 0.0..1.0 | below 1.0, provenance is a sample and the manifest says so | config |
| audit | null | cell address | reconstructs one cell's raw value and exits | CLI |

## Alternatives

Seam: ProvenanceSink — record(cell, source, rule) -> void

| alternative | why you'd swap | swap cost |
|---|---|---|
| column-level provenance only | orders of magnitude smaller | --audit can no longer explain one anomalous value, which is its main use |
| W3C PROV-O graph | a standard others can consume | a triple store to query what a Parquet join already answers |

## Trap

Recording the vocabulary release name without its hash. Releases are re-cut, so the name alone makes a rerun that silently used different mappings look identical in the manifest.

## Not here (nogo)

Do not write provenance as a log file — it must be joinable. Never omit the pack hash. Do not let a disease term, gene symbol or cohort name reach process logic.
