# §8.2 — Classify missingness as systematic or sporadic, per cohort

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

A cohort that never measured a variable and a cohort missing it for twelve patients are different problems with different remedies. The distinction is invisible in a pooled missingness rate and obvious in a cohort-by-variable heatmap.

## I/O

```
IN   coverage/matrix.parquet
OUT  coverage/missingness.parquet (cohort_id, variable, class, frac_missing)
     coverage/missingness_heatmap.png
SIDE none — this stage never imputes
```

## Contract

```
class ∈ { systematic,   # frac_missing == 1.0 for this cohort
          near_systematic, # >= systematic_threshold
          sporadic,     # scattered within the cohort
          complete }

# Imputing a SYSTEMATIC variable inside a cohort with zero
# observations of it is pure between-cohort extrapolation wearing a
# within-cohort mask, and its uncertainty is understated by exactly
# the amount that matters. The class is emitted so a consumer cannot
# do that accidentally.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| systematic_threshold | 0.95 | 0.5..1.0 | above this missing fraction a variable is near-systematic for that cohort | config |
| emit_missingness_heatmap | true | boolean | the plot that separates the two classes by eye | config |
| min_cohort_n | 20 | 1..10^5 | below this, classification is reported as unreliable rather than asserted | config |

## Alternatives

Seam: MissingnessClassifier — classify(cohort, variable) -> Class

| alternative | why you'd swap | swap cost |
|---|---|---|
| impute here with multilevel MICE | one artifact, ready to model on | bakes an assumption into the canonical output that every consumer then inherits |
| test MCAR (Little's test) | an actual statistic rather than a threshold | the test is about the mechanism, not the pattern, and is badly underpowered at few cohorts |

## Trap

Reporting one missingness rate per variable across cohorts. It averages a cohort with 100% missing and one with 0% into a plausible-looking 50%, which is exactly the number that licenses the wrong imputation.

## Not here (nogo)

Do not impute anything. Never collapse the cohort dimension. Do not omit a cohort with complete missingness from the heatmap — it is the clearest signal on it.
