# §2.2 — Normalise candidate units without committing to one

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

A unit written in a header (PDL1 (%), CREAT_mgdL) is evidence, not truth. Parsing it into UCUM here lets §4.2's unit-plausibility channel score it against the value range, which is the only channel that catches a days/months confusion.

## I/O

```
IN   profiles/*.json  (column name + quantiles)
OUT  same records, `candidate_units` populated: [{ucum, source, confidence}]
SIDE none; ambiguity is RECORDED, never resolved here
```

## Contract

```
# candidate_units — ordered, never a single value
[ { "ucum": "%",      "source": "header:(%)",   "confidence": 0.9 },
  { "ucum": "1",      "source": "range:0..100", "confidence": 0.3 } ]

# A column with NO parseable unit gets [] — not a guessed default.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| unit_header_patterns | assets/unit_patterns.yaml | path | the regexes that lift a unit out of a header | config |
| ucum_release | 2.2 | version string | pins the unit grammar; recorded in the manifest | config |
| infer_unit_from_range | true | boolean | adds a low-confidence candidate from the value range alone | config |

## Alternatives

Seam: UnitParser — parse(header, quantiles) -> [UnitCandidate]

| alternative | why you'd swap | swap cost |
|---|---|---|
| a UCUM library parser | full grammar rather than a pattern list | an extra container; most clinical headers are not valid UCUM anyway |
| LOINC-driven units | the concept already declares its expected unit | only works once a candidate concept exists — i.e. after §4, not before |

## Trap

Emitting one unit instead of a ranked list. mg/dL to mmol/L is an analyte-specific factor, so a single committed guess is a silent conversion error later; a ranked list lets §6.2 refuse and the ledger show why.

## Not here (nogo)

Do not convert any value. Do not default an empty candidate list to the concept's expected unit — that is §6.2's decision and it must be recorded.
