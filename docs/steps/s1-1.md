# §1.1 — Validate the two-level samplesheet into a typed channel

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

The samplesheet is the pipeline's own entry point, not a handshake with an upstream tool (principle 5). Validating it here means every later stage can assume a cohort id, a dataset role and a holdout flag exist, and no later stage needs a null check.

## I/O

```
IN   --input  samplesheet.csv
     --concept_pack  assets/packs/<name>.yaml | path | url
OUT  ch_datasets : [ meta(cohort_id, dataset_id, role, holdout), path(table) ]
     ch_pack     : [ pack_hash, [variable, ...] ]
SIDE fails fast on duplicate (cohort_id, dataset_id); writes no files
```

## Contract

```
# assets/schema_input.json -> validated by nf-schema
cohort_id,dataset_id,role,path,holdout
COHORT_A,clinical,clinical,/data/a/clin.csv,false
COHORT_A,treatment,treatment,/data/a/tx.parquet,false
COHORT_B,clinical,clinical,/data/b/clin.tsv,true

# role  : enum — clinical | treatment | biopsy | imaging | other
# holdout: boolean — see §1.2; excluded at channel construction
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| input | — | path | the two-level samplesheet | CLI, required |
| concept_pack | assets/packs/minimal.yaml | path or url | declares the target variables; the pipeline has no other notion of what to map to | CLI |
| allow_single_dataset | false | boolean | permits a cohort with one dataset (skips §3 entirely for it) | config |

## Alternatives

Seam: SheetReader — read(path) -> [(Meta, Path)]

| alternative | why you'd swap | swap cost |
|---|---|---|
| nested YAML sheet | expresses cohort→dataset nesting natively; no repeated cohort_id | loses nf-schema CSV validation; one custom validator |
| an OMOP-native manifest | a cohort already in CDM form skips §6 entirely | a second entry path and a second schema to keep in step |

## Trap

Making cohort_id the primary key. It is not: (cohort_id, dataset_id) is. A sheet with two rows sharing both is a silent duplication that survives to the emitted tables, where it looks like a linkage failure in §3.

## Not here (nogo)

Do not read a single byte of any table. Do not infer role from a filename. Never accept a sheet lacking the holdout column — absent is not false.
