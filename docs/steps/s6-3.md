# §6.3 — Map value vocabularies, and show every collapse

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Mapping values is where distinctions die. Four source grades collapsing into two canonical ones is sometimes correct and sometimes the destruction of the effect being studied, and only a picture of the collapse lets anyone tell which.

## I/O

```
IN   mapped rows with categorical values + value-map rules
OUT  same rows, value_as_concept_id set
     qc/value_collapse.json  [{rule_id, from:[str], to:str, n_rows}]
     qc/alluvial_<variable>.png   raw value -> canonical concept
SIDE none
```

## Contract

```
# A collapse is recorded with its FAN-IN, always.
{ "rule_id": "R-0207", "variable": "ecog",
  "from": ["0","1"], "to": "0-1", "n_rows": 812,
  "fan_in": 2 }        # fan_in > 1 is a lost distinction, by definition

# qc/alluvial_ecog.png — every source value on the left, canonical on
# the right, ribbon width = n_rows. Emitted unconditionally.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| max_fan_in_warn | 3 | 1..20 | a collapse wider than this is flagged in the QC report | config |
| emit_alluvial | true | boolean | the plot that makes a collapse visible at all | config |
| unmapped_value_policy | manifest | manifest|fail | whether an unmappable value stops the run or is recorded | config |

## Alternatives

Seam: ValueMapper — mapValue(str, Rule) -> concept_id?

| alternative | why you'd swap | swap cost |
|---|---|---|
| keep the finest common grain | never collapses; downstream chooses | fails when two cohorts' grains do not nest, which is the usual case |
| emit both raw and canonical columns | the collapse stays reversible in the output | widens every domain table and pushes the decision to every consumer |

## Trap

Treating best response as a value to map. It is an endpoint derived from a scan sequence under a criteria version (§7.3); mapping the source's stated string silently imports whichever criteria that cohort used, unrecorded.

## Not here (nogo)

Do not collapse a value set without writing its fan_in. Never suppress the alluvial plot because the collapse looked obvious.
