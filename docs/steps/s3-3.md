# §3.3 — Threshold into links, and emit the match-weight histogram

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

The histogram is a mixture of two distributions, and the overlap region is the only honest picture of what a threshold choice costs. It is emitted unconditionally because the run that most needs it is the run nobody thought to ask for it.

## I/O

```
IN   link/scores.parquet
OUT  link/links.parquet        (person_id, cohort_id, [source_row_id])
     link/match_histogram.png  both thresholds marked
     link/link_report.json     { n_in, n_persons, n_clerical, collapse_ratio }
SIDE none
```

## Contract

```
weight >= match_threshold          -> link
clerical_threshold <= w < match    -> CLERICAL review band, reported not linked
weight <  clerical_threshold       -> distinct

# link_report.json
{ "n_in": 1240, "n_persons": 1105, "collapse_ratio": 0.891,
  "n_clerical": 37 }   # collapse_ratio far from 1.0 is the alarm
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| match_threshold | 12.0 | match weight | above it, two records are one person; lowering it over-links | config |
| clerical_threshold | 6.0 | match weight | the review band; pairs here are reported, never auto-linked | config |
| max_collapse_ratio_drop | 0.5 | 0.0..1.0 | fails the run when linkage collapses more than half the records | config |

## Alternatives

Seam: Resolver — resolve([ScoredPair]) -> [PersonCluster]

| alternative | why you'd swap | swap cost |
|---|---|---|
| connected components | simplest clustering; what splink does by default | one bad edge chains two people into one cluster transitively |
| hierarchical / star clustering | resists transitive chaining | a second parameter, and clusters stop being reproducible from links alone |

## Trap

Tuning the threshold until N looks right. N is the thing being measured; using it as the target makes the linkage unfalsifiable. Tune on the clerical band's contents, which are readable, and let N land where it lands.

## Not here (nogo)

Do not auto-resolve the clerical band. Never suppress the histogram when the run looks clean. Do not let a threshold be chosen by any statistic computed on the outcome.
