# §7.2 — Derive time and event together, under the pack's estimand

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Time and event are one derivation, not two columns. Splitting them is how a cohort ends up with an event flag from one convention and a duration from another, which no schema check catches because both columns are individually valid.

## I/O

```
IN   normalised dates + pack variables with domain: derived
OUT  derived/endpoints.parquet
     (person_id, cohort_id, endpoint, time_days, event, censor_reason,
      time_zero_rule, precision, criteria_version)
     qc/km_<endpoint>_by_cohort.png
SIDE fails when a survival curve is non-monotonic
```

## Contract

```
time_days = (event_or_censor_date - time_zero_date).days
event     = 1 if the pack's event condition holds else 0

# Source event codings are DECLARED, never inferred:
event_coding: {censored: 1, event: 2}   # or {0,1} — per cohort

# Post-condition, checked: the KM curve is non-increasing.
# A RISING curve is an inverted event coding, and it is the only
# cheap detector — {1,2} is a plausible 0/1-shifted flag, so the
# unique-value set alone cannot tell the two codings apart.
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| time_zero | treatment_start | treatment_start|diagnosis|enrolment | the design decision immortal-time bias hides in | pack |
| event_coding | {censored: 0, event: 1} | map | per-cohort declaration; never inferred from the value set | samplesheet |
| competing_risk_policy | separate | separate|censor | whether death from another cause is a competing event or censoring | pack |
| fail_on_rising_km | true | boolean | a non-monotonic survival curve stops the run | config |

## Alternatives

Seam: EndpointDeriver — derive(person, Pack) -> [Endpoint]

| alternative | why you'd swap | swap cost |
|---|---|---|
| copy a pre-derived OS column | trivial; the cohort already computed it | imports an undeclared estimand — its time zero is unknown and unrecorded |
| emit a target-trial clone table | makes time zero and eligibility explicit per Hernán & Robins | a second output model, and the pack must declare eligibility too |

## Trap

Assuming censoring is coded 0/1. Cohorts use 1/2 at least as often, and {1,2} is a perfectly plausible shifted flag — so the coding must be declared per cohort and the KM curve is the only thing that catches a wrong declaration.

## Not here (nogo)

Do not infer event_coding from the data. Never let time zero follow an eligibility-defining event — that manufactures immortal time. Do not censor a competing event silently.
