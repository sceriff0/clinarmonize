# §5.2 — Compile decisions into versioned, addressable mapping rules

> Extracted verbatim from `docs/schematics/p-harmonize.html`.
> Per §0.2: read §0 and this card. Read nothing else.

## Why

Provenance requires that every emitted cell name the rule that produced it. Rules must therefore be first-class, addressable and versioned — otherwise --audit can report a value's origin but not the reasoning that transformed it.

## I/O

```
IN   ch_confirmed
OUT  rules/ruleset.json   [ {rule_id, rule_version, kind, from, to, params} ]
SIDE none; rule_id is a content hash, so an unchanged rule keeps its id
```

## Contract

```
{ "rule_id": "R-0142",                 # stable: hash of (kind, from, to, params)
  "rule_version": "1.2.0",             # the PACK version that produced it
  "kind": "column_map|value_map|unit_convert|derive",
  "from": {"cohort_id":"COHORT_A","dataset_id":"clinical","column":"PDL1_PCT"},
  "to":   {"variable":"pdl1_tps","concept_id":4245277},
  "params": {"unit_in":"%","unit_out":"%","factor":1.0} }
```

## Params

| name | default | domain | effect | set by |
|---|---|---|---|---|
| rule_id_prefix | R- | string | cosmetic; the id's stability comes from the content hash | config |
| fail_on_rule_collision | true | boolean | two rules writing the same target cell is a defect, not a merge | config |

## Alternatives

Seam: RuleCompiler — compile([Decision]) -> [Rule]

| alternative | why you'd swap | swap cost |
|---|---|---|
| SQL views per cohort | readable by anyone who knows SQL; no rule engine | provenance stops being per-cell and becomes per-query |
| sequential rule id | friendlier to read in a report | an unchanged rule gets a new id on reorder, so diffs become noise |

## Trap

Deriving rule_id from position or time. Provenance rows then point at ids that shift between runs, and an audit against an older output silently resolves to the wrong rule — which is worse than failing to resolve.

## Not here (nogo)

Do not apply any rule — §6 does that. Never merge two rules that write the same target cell; fail and name both.
